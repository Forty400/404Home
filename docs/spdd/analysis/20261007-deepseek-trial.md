## 1. Problem

404Home 目前只是 AI 工具导航 + CMS，认证仅限后台 `admins`。用户无法在站内直接试用大模型，也无法用微信/邮箱建立 C 端身份与额度。

不做则：流量只停在「外链跳转」；无法验证 DeepSeek 试用转化；也无法用自有 API 额度做可控体验。

## 2. Goals / Non-goals

**Goals**

- 接入 DeepSeek API（运营自购约 **100 元** 额度），在服务器侧代理调用并计费扣减。
- 提供 **桌面 + 手机浏览器**（响应式 Web）的 DeepSeek 对话试用；**不做小程序**（D10）。
- 使用前必须注册/登录：支持 **微信**（主）或 **邮箱+密码**（备）；邮箱与微信可绑定。
- 按 VIP 等级给额度（D7）：普通 ¥3；VIP1 ¥10；VIP2 ¥20；VIP10 ¥100 等；**累充**升级；可配置扩展中间档。
- 账号与余额写入服务器 SQLite（可后续迁库，首期沿用现有 SQLite）。
- 完善网站注册登录并接入微信；邮箱账号与微信账号冲突时提供 **绑定 / 合并 / 注销** 选项。
- 过程中遇阻及时反馈；长任务不擅自取消。

**Non-goals（首期明确不做）**

- 不做短信 OTP、不做手机号登录。
- 不做多模型市场（仅 DeepSeek 一路）。
- 不做完整财务合规开票体系；充值通道可先做「管理员人工加额」或单一支付方式（见开放问题）。
- 不替换现有 `/admin` 管理员体系；C 端用户与管理员身份分离。
- 不在前端暴露 DeepSeek API Key。

## 3. Users & Scenarios

| Actor | Scenario | Success |
| --- | --- | --- |
| 访客 | 打开网页试用页 | 被引导注册/登录后再对话 |
| 新用户 | 邮箱+密码注册（过图形验证码） | 获得约 3 元试用余额（是否需邮箱验证见后续决策） |
| 新用户 | 微信授权登录（网页/小程序） | 创建账号；可再绑邮箱 |
| 已有邮箱用户 | 登录后绑定微信 | 同一 user，余额共用 |
| 已有微信用户 | 绑定邮箱 | 可用邮箱+密码登录同一账号 |
| 双端用户 | 桌面聊过，再用手机浏览器（或反过来） | 同一账号看到同一会话/问答记录 |
| 冲突用户 | 待绑微信已关联别的账号，或邮箱已被占用 | 看到绑定失败原因，可选合并或注销其一 |
| 试用用户 | 发消息对话 | 流式/非流式回复；按用量扣余额；余额不足提示充值/停用 |
| 充值用户 | 累充达到下一档阈值 | 自动升至对应 VIP，cap 提高到该档额度 |
| 加额用户 | 管理员加额（首期） | 余额不超过当前等级 cap；是否计入累充见开放问题 |
| 管理员 | 必要时手工改等级/加额 | 以配置表为准，写账本 |
| 运营 | 自购 DeepSeek 约 100 元额度 | Key 仅存服务端；可看健康检查与粗粒度用量 |
| 管理员 | 后台加额/封禁/查账 | 不依赖改 DB 手工 SQL（至少具备最小运维接口或脚本） |

## 4. Constraints

- Tech: 现有 Vue3 + Koa + SQLite；JWT 已有但仅服务 `admins`；无用户表、无微信、无钱包、无模型代理。
- Budget: DeepSeek API 约 **¥100** 由运营自购；单用户试用约 **¥3**，充值后约 **¥20** 上限。无短信费用。
- Ops / security:
  - API Key、微信 AppSecret、邮件服务密钥只放服务器环境变量 / `deploy.local.md` 同类私密文件，不进 git。
  - 所有模型调用必须服务端代理；按用户鉴权 + 余额校验。
  - 防刷：注册图形验证码、同 IP 注册限流、对话 QPS、单日消耗上限。
- Time: 大需求，必须分阶段交付；见路线图画布。
- Product: 不做小程序；需域名 + HTTPS；微信仅网站应用扫码（D2）。

## 5. Risks

| Risk | Impact | Mitigation |
| --- | --- | --- |
| ¥100 总池被刷光 | 全体不可用 | 单用户上限、图形验证码、IP/设备频控；可选邮箱验证后再发赠送金 |
| Token→人民币换算偏差 | 亏本或体验不公 | 用官方计价 + 可配置加成系数；账本记录 token 与扣费 |
| 微信开放平台 vs 小程序主体不一致 | 无法打通 UnionID | 尽量同一主体；否则以「绑定邮箱」为跨端合并主键 |
| 邮箱未验证被刷号 | 赠送金被薅 | 图形验证码+限流；开放问题：是否强制邮箱验证后发额 |
| 绑定/合并做错 | 余额丢失/串号 | 合并事务 + 账本迁移 + 软删除；操作需二次确认 |
| 微信资质/HTTPS 未就绪 | 微信登录阻塞 | 开发期可模拟微信登录（仅非生产）；邮箱密码可先上线 |
| 国内访问港站偶发慢 | 体验波动 | Cloudflare 代理/优化；日后可再评估大陆节点 |
| SQLite 并发写 | 高峰锁表 | 短事务；对话异步落账；后续可迁 Postgres |
| 与 admin JWT 混用 | 权限穿透 | 独立 `users` 表 + 独立 JWT claim（`role: user`） |

## 域名采购建议（港机、暂不备案、国内可访问）

前提：服务器在香港 → 解析到港机 **一般不需要 ICP 备案**；不做小程序后，也**不再被**「小程序合法域名必须备案」卡住。仍建议上 **HTTPS**（微信网站应用回调、现代浏览器都需要）。

| 渠道 | 适合你们吗 | 优点 | 注意 |
| --- | --- | --- | --- |
| **[Cloudflare Registrar](https://www.cloudflare.com/domains/)** | **首选之一** | `.com` 接近成本价、续费不宰客；自带 DNS/CDN/SSL，国内访问港站常比裸 IP 稳一点 | 域名须用 Cloudflare DNS；需能注册/支付 CF 账号 |
| **[Porkbun](https://porkbun.com/)** | **首选之一** | 注册/续费同价、含隐私保护、可改 NS；操作友好 | 价格略高于 CF 分位数；DNS 可再指到 Cloudflare |
| **Namecheap** | 一般 | 常见、支持多 | **续费往往明显更贵**，长期不划算 |
| **阿里云 / 腾讯云** | **仅有微信/支付宝时首选** | 支持微信/支付宝；国内实名顺；解析到**香港仍通常免 ICP** | 须实名信息模板；别把解析指到大陆机触发备案 |
| 万网/其它国内零售 | 不优先 | — | 续费与捆绑复杂，收益不大 |

**后缀**：优先 **`.com`**。不必为「免备案」去买 `.hk`/冷门后缀。

**推荐组合（省事）**  
1. Cloudflare 或 Porkbun 注册 `你的品牌.com`  
2. DNS 用 Cloudflare（橙云代理可选）→ A 记录指到香港服务器  
3. 源站 Nginx 配证书，或用 CF 提供的 HTTPS  

**购名前**：先在注册商搜索是否可注册；避开纯商标大词；与 404Home / 试用品牌一致即可。

购入后请把**最终域名**发我，写入 deploy 知识与环境变量清单。

## 9. Phased delivery（后续规划摘要）

| Phase | 主题 | 可验收结果 |
| --- | --- | --- |
| P0 | 用户表、邮箱+密码+图形验证码、C 端 JWT、网页注册登录壳 | 能注册登录，与 admin 隔离 |
| P1 | 钱包 + VIP 累充档位（D7） | 余额/升档/档差补额正确 |
| P2 | DeepSeek 代理：服务端 Key、计费扣减、网页简易聊天页 | 登录用户可对话并扣费 |
| P3 | 微信登录 + 邮箱绑定 + 合并/注销（含 D8 冷却） | 绑定/冲突/注销可测 |
| P4 | 手机浏览器响应式适配（试用/登录/聊天） | 窄屏可用，与桌面同一后端 |
| P5 | 充值（微信支付）+ 防刷加固 + 运维看板 | 用户自助充到上限；运营可观测 |

推荐实现顺序：**P0 → P1 → P2（桌面 Web）→ P3（微信网站应用）→ P4（移动 Web 适配）→ P5**。  
并行：购域名 + HTTPS（越早越好）。
