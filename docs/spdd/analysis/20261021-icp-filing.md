## 1. Problem

生产站已落在**腾讯云中国大陆**机（`111.230.147.223`），域名 `forty40.online` / `www.forty40.online` DNS 已指向该 IP。未完成 **ICP 备案** 时：

- 国内经 DNSPod 访问域名会被**未备案拦截**，无法稳定用域名打开站点；
- Let's Encrypt HTTP-01 校验落到拦截页，**HTTPS 无法申请**；
- 微信网站应用、正式品牌域名、后续合规抽查均被卡住。

不做备案则只能继续以 **裸 IP** 验收/运营，不符合「域名 + HTTPS + 中国大陆托管」的长期形态，也不满足工信部/公安对境内网站的基本要求。

既有决策回顾：D10/D11 曾按「港机 + 暂缓域名」延后备案；现生产已切大陆腾讯云且港机废弃（见 `docs/spdd/rag/knowledge/404home-deploy.md`），**备案从「可选项」变为阻塞项**。

## 2. Goals / Non-goals

**Goals**

- 完成 `forty40.online`（含 www）在腾讯云侧的 **ICP 首次备案**（或接入备案，若主体已有号）。
- 备案通过后：**解除域名拦截 → 申请并启用 HTTPS → 页脚悬挂 ICP 号（链到工信部）**。
- 站点开通后 **30 日内**办理 **公安联网备案**，并通过后悬挂公网安备号。
- 网站内容与备案信息一致：名称、主体、服务内容描述与实际业务（工具导航 + AI 试用）可核验，避免驳回/抽查下线。
- 沉淀可执行的运维清单，更新 deploy 知识与（必要时）架构规范/ADR（废止「大陆机可不备案」的过时表述）。

**Non-goals**

- 本期不做经营性 ICP 许可证（ICP 证）申请（除非主体与业务明确要求「经营性」且监管要求办证）。
- 本期不迁移回香港机「绕过备案」。
- 不在本分析阶段改业务功能（计费规则、微信登录等）；代码侧仅预留/实现合规展示（页脚备案号）可进后续画布。
- 不替代律师意见；各省管局细则以提交时腾讯云/管局页面为准。

## 4. Constraints

- Tech:
  - 接入资源必须是账号内**支持备案**的腾讯云大陆实例（当前生产 CVM/轻量等需在备案控制台可选）。
  - 域名须完成**实名认证**，且注册商/后缀在工信部允许备案范围内（`.online` 一般可备，以控制台校验为准）。
  - 备案期间/驳回期间继续以 IP 验收；勿在未通过前强推域名给国内用户。
- Time:
  - 腾讯云初审通常数个工作日；管局常见约 **20 个工作日**内（省际差异大）。
  - 公安联网备案：网站开通后 **30 日内**提交；审核常见数周。
- Ops / security:
  - 备案联系人手机须畅通（初审外呼）；主体信息与腾讯云实名一致。
  - 证件原件彩照/扫描规范：清晰、完整边框、有效期距提交日通常 ≥3 个月等（见腾讯云材料规范）。
  - 密钥与 `deploy.local.md` 仍不入仓；备案材料含身份证等 PII，**仅本地/云控制台**，勿写入 git。
- Product / legal（广东 + 个人，已定 D1/D3）:
  - 个人只能办个人性质站；**注册计费 + AI 对话**与口径冲突风险高，提交前宜把对外呈现收敛为「个人作品集 / 工具导航 / 学习演示」，避免企业化文案与公开「充值商城」观感；通过后抽查仍要求内容与备案相符。
  - 网站服务内容个人侧一般选「其他」；前置审批选「都不涉及」（若不涉及新闻/出版等）。
  - 网站名称建议纯中文或中英混合、个人属性，如「404Home 个人工具站」；备注简要写清栏目（工具收录、个人试用演示等）。
  - 主域名与 `www` 指向同一站时，备注写「所有域名指向同一网站」。

## 5. Risks

| Risk | Impact | Mitigation |
| --- | --- | --- |
| 个人主体 vs 计费/AI 站被驳回或事后抽查 | 备案失败或接入被断 | 备案期弱化「商用充值」表述；备注写个人作品集/工具导航；长期有执照再迁单位主体 |
| 广东承诺书/双手机号/外省户籍材料不全 | 初审或管局驳回 | 按 §0 清单一次备齐再提交 |
| 备案信息与线上内容不一致 | 责令整改或断开接入 | 名称、负责人、栏目与页脚主体一致；保留内容安全与投诉入口 |
| 仅做 ICP、忽略公安备案 | 合规缺口 | 开通后 30 日内办公安备案并挂号 |
| 备案通过前用域名强推 | 用户打不开、证书失败 | 对外仍宣传 IP；通过后再切域名+HTTPS |
