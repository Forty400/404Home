## R · Requirements

### Business goal

统一首屏叙事、压缩移动顶栏、收敛「热门」、加厚工具/文章决策信息，并让未登录用户看懂 Trial 价值后再登录。

### In scope

- UX-04～UX-10（见 ADR 拍板）

### Out of scope

- 文章搜索分区、未登录真调用模型、行为数据热榜、改色板

### Acceptance criteria

- [x] Hero 标明内容站 +「搜工具」；首屏更易见文章卡
- [x] 移动：登录进菜单；顶栏更矮；分类有「更多」
- [x] 热门配额生效；侧栏「精选」且与 Feed 去重
- [x] 工具详情展示定价/地区/场景；相关工具对比可见
- [x] 搜索空/0 结果有可点引导
- [x] 文章正文有可读厚度（seed/补厚）
- [x] Trial 未登录有静态预览 + 额度说明 + CTA
- [x] P0 自动化绿

## A · Approach

1. 纯函数：`pickFeaturedRank`、`SEARCH_HINTS`；Vitest 锁定。
2. seed 启动：配额热门 + 短正文补厚 + 若干工具决策字段回填。
3. UI：压缩 Hero/Header；Trial 预览替换硬墙；详情决策条。
