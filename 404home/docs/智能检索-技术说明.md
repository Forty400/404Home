# 404Home 智能检索（RAG + MCP）技术说明

面向维护者 / 面试口述：这套能力在仓库里**做了什么、怎么串起来、证据在哪**。

设计契约：`docs/spdd/canvases/20261105-tool-rag-mcp.md`（镜像：`AI指导文档/`）。  
决策：`docs/spdd/2-adr决策/ADR-20261105-tool-rag-mcp.md`（局部解冻 portfolio-freeze）。

---

## 1. 一句话

在现有 Vue3 + Koa + SQLite 上，为 `tools` 表增加 **实体切分 → 向量索引 → 双路召回 → RRF 融合 → LLM 精排 top-5 + 理由**，对外提供 `POST /api/smart-search`、前台 `/smart-search`，以及只读 **MCP 三工具**；**不改坏**原 `/api/tools` LIKE 搜索与 `/trial` 计费。

---

## 2. 数据流

```text
tools 行
  → toolChunker（name/summary/tags/scenario/card）
  → embeddings（OpenAI 兼容；测试用 EMBEDDING_STUB）
  → SQLite tool_chunks(embedding_json)

用户 query
  → 关键词路（CJK 分词/字串 LIKE，按 tool 去重 top-20）
  → 向量路（余弦，阈值过滤，按 tool 去重 top-20）
  → RRF(k=60) 融合（候选 ≤40）
  → LLM 精排 JSON[{tool_id,reason}]（失败则降级 RRF，meta.degraded=true）
  → HTTP / MCP / 前台
```

## 4. API

`POST /api/smart-search`

```json
{ "q": "适合做海报的免费 AI", "rerank": true }
```

成功：`{ items:[{ rank, score, reason, tool:{id,name,slug,summary,url,tags} }], meta }`  
空查询：`400 INVALID_QUERY`  
未配置 Embedding 且非 stub：`503 EMBEDDING_NOT_CONFIGURED`  
无命中：`200 items=[]`（不 500）

`POST /api/smart-search/reindex`（需 admin JWT）

## 5. 环境变量（见 `server/.env.example`）

| 变量 | 说明 |
| --- | --- |
| `EMBEDDING_API_KEY` / `BASE_URL` / `MODEL` | OpenAI 兼容嵌入（例：硅基流动 + bge-m3） |
| `EMBEDDING_STUB=1` | 离线稳定伪向量（单测 / 本地无 Key） |
| `DEEPSEEK_STUB=1` | 精排 stub（不写外网） |
| `SMART_SEARCH_RERANK` | 默认开；`0` 则直接 RRF top-5 |
| `SMART_SEARCH_RATE_LIMIT_PER_MIN` | 默认 20 |
| `VECTOR_BACKEND` | 默认 `sqlite`（qdrant 未实现） |
| `RRF_K` / `RETRIEVE_K` / `RERANK_TOP_N` | 60 / 20 / 5 |

默认**不扣费**（与 `/trial` 钱包无关）。

## 6. 怎么跑

```bash
cd 404home
npm install && cd server && npm install && cd ..

# 测试（含 smart-search P0）
npm test

# 本地演示（stub 即可）
cd server
set EMBEDDING_STUB=1
set DEEPSEEK_STUB=1
npm run reindex:tools
npm run eval:recall
cd ..
npm run dev
# 打开 http://localhost:8080/smart-search
```

评测示例输出（stub 环境、golden 20 条）：

```text
AVG Recall@5 (20 queries)     25.4%     95.4%
Resume line: Recall@5 25% → 95%
```

> 真实 Embedding + 真实 LLM 精排后数字会变；简历请填**你本机脚本 stdout**的最新值。

### MCP

见 `mcp-server/README.md`。需先起 API，再在 Cursor 配 `node …/mcp-server/index.js`。

## 7. 与旧搜索的关系

| | 关键词搜索 `/search` | 智能检索 `/smart-search` |
| --- | --- | --- |
| API | `GET /api/tools?q=` LIKE | `POST /api/smart-search` |
| 语义 | CMS 列表过滤 | RAG 双路 + 精排 + reason |
| 计费 | 无 | 默认无 |

两者并存，故意不改写旧接口，避免破坏后台与既有前端。

## 9. 已知简化（shortcut）

- Stub embedding 是确定性 bag-of-char，仅保证链路与单测；生产请配真实 Embedding。
- 向量余弦阈值 `0.55` 用于压噪声；换模型后可能要调。
- MCP 经 HTTP 调本机 API，不内嵌 SQLite。
- `VECTOR_BACKEND=qdrant` 预留未实现。
